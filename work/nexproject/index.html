PROJECT MANAGEMENT

A clearer view of delivery work.

A project management product. I worked on ticket dashboards and updated views for ticket details, sprints, and version tasks.

Role
Ticket dashboard, sprint detail, and version task design
Scope
Tickets, sprint detail, version tasks
Platform
Web app
01

Context

How can teams go from the delivery overview to the item that needs attention?

Project teams need to scan a list, inspect a work item, and understand where it sits in a sprint or release. Those views have different levels of detail, but should make the next step recognizable.

Explore the workflow

Three views into the design work.

01 / TICKETS

Move from overview to detail

I worked on the ticket dashboard and updated the ticket table and detail view. The table supports scanning across tickets, while the detail view gives a single issue more room.

Design lens · Overview and detail
02 / SPRINTS

Show work in its sprint context

I updated the sprint detail experience. A sprint provides the time window and context for the individual work items it contains.

Design lens · Planning context
03 / VERSIONS

Make release tasks easy to locate

I updated the version task table and task view. This provides another way to move from a release-level overview to an individual task.

Design lens · Consistent navigation
